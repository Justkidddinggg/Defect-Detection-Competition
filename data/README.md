# Data

Download `train.csv` and `test.csv` from the SECOM Defect Detection
competition page on Kaggle and place them in this folder:

```
data/
├── train.csv   # 1,253 rows, id + time + 590 sensor features + target (-1 pass / 1 fail)
└── test.csv    # 314 rows, id + time + 590 sensor features
```

The data is not redistributed in this repository (see `.gitignore`).
